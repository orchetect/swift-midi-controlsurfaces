# Getting Started

A quick guide on getting started using SwiftMIDIControlSurfaces.

![swift-midi-controlsurfaces](swift-midi-controlsurfaces-banner.png)

## 1. Import the Library

Add the SwiftMIDIControlSurfaces module to your project, and import it.

```swift
import SwiftMIDIControlSurfaces
```

## 2. Example Code

See the **HUI Example** example project for a demonstration of ``HUIHost`` and ``HUISurface``.
